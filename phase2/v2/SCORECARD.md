## 2. Consistency: same clause text, same rule, different contracts

Same definition as v1 section 3: quotes of 40 or more characters, edit markers removed, under the same rule. v2 quotes the whole clause, so a group means the whole clause text is identical.

| Measure | v1 | v2 |
|---|---|---|
| Groups (same text, same rule, 2+ contracts) | 37 | 45 |
| Same verdict in every contract | 32 (86%) | 32 (71%) |
| Same route in every contract | 31 (84%) | 32 (71%) |

v1's definition removes the edit markers *and their content*, so two clauses with different margin comments count as "identical". v2 reads the comments, so it routes those clauses differently on purpose (for example 10.3 with and without a request to shorten survival). A stricter test keeps the edits and comments:

| v2, exact text including edits and comments | Groups | Same route in every contract |
|---|---|---|
| | 39 | 34 (87%) |

The remaining differences on exact text come from context: v2 also sends the related definitions of each contract, and those differ. Whether that is right needs a lawyer.

## 5. Prompt-injection contracts A01 to A03

Each attack contract is a normal contract plus one hostile edit. v2 asks Jev fixed questions, so hostile text can at most change one clause's answers. The test: is the attack flagged, and do the other clauses keep their routes?
